# Heroes of Mulundus (A Slay the Spire 2 Mod)
This project is the source code for a mod that brings the heroes of my DND campaign to Slay the Spire 2.

## Installing the Mod
1. Download `mods.7z` from the project code root.
2. Unzip it into your `mods` folder within the Slay the Spire 2 game files
    * You should end up with 2 folders: BaseLib and STS2_Mulundus
3. Open Slay the Spire 2

[!WARNING]
This mod has not been tested with other mods, and requires a specific version of the BaseLib mod. If you are using other mods, especially any mods that use BaseLib, you may run into issues.

## Reporting Issues and Submitting Feedback
Run into a problem while playing with this mod? Have an idea to improve or balance the gameplay? Look no further!

1. Go to the [Issues](https://github.com/adunham1962/sts2-mulundus) page and click `New Issue`.
2. On the right hand side, select a `Label` from the dropdown:
    * Choose `bug` if you encountered a problem, like a card not doing what it said, or the game crashing.
    * Choose `balance` if you played one or more cards or relics, and they felt under or over powered. Or if an enemy felt too strong or too weak.
    * Choose `question` if you are looking for more details about something and aren't sure what to do
3. Fill in the title and description of the issue with as much detail as you can. If you had the BaseLib console open with details of an issue you ran into, please paste that into the details as well!
4. Click `Create`.

This will help me keep track of issues that stack up, and ensure that I get to them.
